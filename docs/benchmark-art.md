# Benchmark art pipeline

The new courtyard, Atlas and costume accessories are original authored geometry and original small brushed color textures, generated by `scripts/benchmark-art.py`. They reuse the established Blender 5.2.1/glTF pipeline and color language. The earlier native concept target is composition reference, not runtime evidence. No new vendor downloads, paid service, image API or external resource creation was used. Existing wizard body/animations remain the credited CC0 Quaternius assembly in `docs/asset-manifest.md`.

The reproducible script is authoritative. This benchmark intentionally does not regenerate or commit a new large `.blend` working file.

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python scripts/benchmark-art.py
node scripts/benchmark-art-optimize.mjs
```

The second command applies glTF Transform dedup/prune while retaining attachment and motion pivots. Runtime files are `public/assets/courtyard.glb`, `guardian.glb`, and `mage-accessories.glb`.

## Environment contract

`courtyard.glb` is added at world origin with unit scale, Y up. It replaces the previous six box/pyramid college wing constructions; do not layer both. Existing observatory, outer walls, garden beds and route paving are separate. New arcades align to wings centered at x=±11, z=-13/-5/3. Their inward facades are x=±8.55. Sloped slate roofs, cornices, segmented arch voussoirs, mullions, broad banners, small recessed books and opaque ivy form the authored facade. Shared materials keep the six wings to ten drawing primitives total with the other courtyard additions.

The social anchor is a small reflecting basin and brass book-dial at (0,0,3). Collision radius about 1.4m; two generous routes pass either side. A reading pocket occupies x=-11.7…-8.2, z=9.3…11.5. Its table/book is centered (-10,0,10.5), radius about .7m. The inaccessible archive door is centered (-12.45,0,10), facing +X; the seal is on x=-12.07. This is an opaque closed architectural feature, not a teleport or invented new region. The lead owns interaction facts/prompts and final collision integration.

September 10 inventory: courtyard 50,991 triangles. September 11 refinement: 26,815 triangles, with the same 10 drawing primitives, 10 materials and 10 packed 128×128 textures; see art-refinement.md. This is resource inventory, not a frame-rate result.

## Atlas contract

`guardian.glb` is Y-up, origin at ground, faces +Z, approximately 3.2m high. Its open atlas breastplate, brass leg mechanism, enamel bracers, map-page shoulder vanes and great meridian give the guardian its chapter identity. The source script has no attack rules or timers.

Stable root groups: `AtlasBody`, `ArmLeft`, `ArmRight`, `Head`, `Core`, `Ring`. All children are material-batched within their group. Rest pivots:

| Group | Pivot x/y/z | Intended presentation |
|---|---|---|
| ArmLeft | -.79 / 2.10 / 0 | Telegraph restrained wind-up or defensive lift |
| ArmRight | .79 / 2.10 / 0 | Telegraph sweep/brace |
| Head | 0 / 2.35 / 0 | Small readable tilt toward target |
| Core | 0 / 1.87 / .43 | Ward/vulnerability brightness or pulse |
| Ring | 0 / 2.01 / -.31 | Slow meridian movement, pose cue |

Guardian has 9,368 triangles, 16 drawing primitives, 5 materials/textures, all 128px. The lead owns runtime intention cues and animation. Transform these pivots, never use their completion to determine gameplay.

## Character accessory contract

These parts add silhouette differences to cloned copies of the existing animated wizard without loading duplicate full body/texture assets. `mage-accessories.glb` contains four root groups. Each has extras `attachBone` and `restWorldCoordinates=true`. Coordinates match the original wizard's unanimated rest pose in world space. Before the first AnimationMixer update, attach each accessory group to its named bone **preserving its original rest-world transform**. Do this with both actor and accessory at the same origin/rotation or convert the authored matrix into the actor's world space first; blindly calling `bone.add()` without preserving the world transform is incorrect.

| Character | Hide original named meshes | New groups and attachment |
|---|---|---|
| Player | None | Existing primary bent crown/brim and lantern implement remain |
| Second mage | `Bent_tailored_crown`, `Traveler_brim`, `Hat_band`, `Hat_enamel_pin` | `PartnerHead` → `Head`: angular folded cap; `PartnerMantle` → `spine_03`: long split mantle |
| Iona | Same four hat meshes, plus `Rowan_staff`, `Staff_lantern`, `Staff_open_circle`, `Short_scholar_capelet` | `IonaHead` → `Head`: brass spectacles and hair comb; `IonaApron` → `spine_03`: practical long work apron, tools and keys; retain visible `Hair_Buns` |

All four accessory groups together: 4,722 triangles, 9 drawing primitives, 3 shared materials/textures. Clone accessory nodes per actor; reuse geometry/textures. This preserves the existing personal color identities and provides real headwear/coat/role differences beyond recoloring. The original wizard material `Identity` contract remains unchanged.

## Manuscript moth

`public/assets/paper-moth.glb` is original project-authored geometry/ink/texture (2026-09-10), reproduced independently with `Blender --background --python scripts/benchmark-moth.py`. It has folded manuscript wings, angular cut-page edges, ink margins/branch veins and a little folded-book body. No third-party imagery or new downloads.

Ground-origin/Y-up/+Z front. Body center y=1.2; wings span x=±1.12 and y=.87…2.05. Root nodes `MothBody`, `WingLeft`, `WingRight`. Wing hinges are (-.065,1.2,0) and (.065,1.2,0); mirrored Y-axis rotations fold them around the body. Small ±.5rad flaps preserve silhouette; vertical bob belongs on the parent actor. No asset animation affects battle rules.

Optimized inventory: 36,540 bytes, 161 triangles, 7 drawing primitives across three animated groups, 3 materials and one packed128px paper texture. Materials are shared across wings/body; ink veins use flat narrow ribbons rather than many tubular meshes. Optimize this asset independently with `node scripts/benchmark-art-optimize.mjs paper-moth`. glTF Transform dedup/prune checked. Isolated real Chromium inspection at two flap phases confirmed folded silhouette, ink linework and stable hinge motion; no gameplay or frame-rate conclusion is inferred. Isolated preview mode is `?mode=moth` in the same benchmark asset viewer.
