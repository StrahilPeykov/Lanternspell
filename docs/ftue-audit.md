# Fresh-player audit — 11 September 2026

Baseline ae70c4b. Fresh independent Chromium context, 1440×900, no save. Actual buttons/WASD; no spellbook, debug state, fixtures or route coordinates. Inspected title → Iona → lantern → moth (free/setup/signature) → field book → guardian planning. This is an agent inspection, not a human usability study.

1. **High — combat overload.** Six cards, Ember, tiers, status expiry, forecast and queue arrive together. The introductory modal explains them before any action. Show one useful action, then setup, then payoff; keep details available on demand.
2. **High — weak teaching payoff.** Basic 5 + setup 4 leaves the 18-HP moth at 9. An unprepared signature also deals 9, so the taught setup is unnecessary in this sequence. Use a modest lesson-health adjustment with the same rules, and display the actual bonus explicitly.
3. **High — uninformed identity choice.** Title asks for color and tradition before any spellcasting. Move identity selection to the field book after practice; use a capable default.
4. **Medium — prose interrupts actions.** Iona repeats navigation in dialogue and a note. Lantern requires reading and a second click to perform an already requested interaction. Field-book reward wraps a concrete upgrade in a generic aphorism.
5. **Medium — persistent noise.** Control legend remains after successful movement. Tradition/chapter subtitle repeats the title. A stale welcome toast remained visible into combat in this run; clear it explicitly at progression changes.
6. **Medium — movement lacks response shaping.** Stops/heading changes snap; no sprint. Orbit stays fixed while travelling sideways. Compare lightweight movement and follow profiles in motion.
7. **Medium — college lacks ordinary purpose.** Symmetric flower beds, brass, books and lamps dominate. Add a few functional signs/maintenance details, with quiet space retained.

What worked: Iona is visible near entry; the lantern, practice moth and book have readable silhouettes; contextual prompts allowed progress. Guardian silhouette and its ward are clear. The travelling crane provides a distinct visible payoff. The name in the margin-note toast disagrees with the active tradition's signature.
