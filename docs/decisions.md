# Decisions

- 2026-09-10: Vanilla Three.js, Vite, TypeScript and DOM UI as requested. No React/engine/ECS.
- One capable mage in solo; no companion. Duo has two actual seats and separate tuning.
- A courtyard garden and observatory establish an inhabited place; ivory plaster, weathered blue roofs, ochre paths, coral flowers, teal clothing and brass star instruments.
- Fixed timing tiers and deterministic visible intentions; no hit/critical randomness. One accumulating resource.
- Native image-generation tool is available; only that subscription-native path is permitted.
- Dependencies are project local with lockfile. Blender is not on PATH; art task will inspect/install a free portable distribution if needed.
- Final QA: batch static geometry after measured draw-call count; use a battle-specific camera framing offset to reserve DOM tray space; commit state first while deferring shared target disappearance and world illumination until presentation ends.
- Small repeated courtyard props and animated spell-page geometry remain reproducible TypeScript geometry rather than additional Blender exports; the hero costume and main architectural landmark retain editable Blender sources. This keeps the bounded effect/scene iteration direct without extra asset-loading machinery.

- Benchmark: direct main by explicit user authorization; cd7b1c5 fast-forwarded, then every verified checkpoint pushed. Preserve history and original editable sources; curate new evidence.
- Full-book traditions provisional default for deliberate planning; seeded four-slot page cycle retained as development comparison. No randomness in hit resolution. New intentions are authoritative planning-boundary state.
- Three signature presentations share outcome; travelling lantern crane provisional favorite for caster-to-target character. Pages remain the quieter alternative.
- Cache surface washes, avoid pre-load proxies, preserve shadow flags, normalize mixed indexed geometry for batching. Low uses1024 shadows with environment casters disabled, reduced effect density, secondary light disabled and.85 pixel ratio.
- Root renderer split by materials/environment/actors/effects; DOM shell/combat and import validation separated from controller. Prettier3.9.6 pinned using official install guidance; no runtime framework.
