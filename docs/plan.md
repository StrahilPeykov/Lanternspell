# First-build plan

Working chapter: **The Sleeping Orrery**, at Bellweather College. A visitor meets keeper Iona, wakes a seed-lantern, practices against a Paper Moth, discovers a margin note that improves the signature Folded Sky spell, then wakes the observatory's brass guardian. Success opens the orrery and lights the courtyard.

1. Scaffold TS/Vite/Three and a walkable, composed courtyard promptly.
2. Pure versioned deterministic battle rules; six prepared spells, Ember resource, fixed timing tiers. Solo and duo tuning.
3. Local SQLite Durable Object authority with two consenting seats, independent plan revisions, joint readiness, durable deduplication; shared rules.
4. Original Blender-authored landmark/clothing and licensed free character inspection; restrained signature constellation/page-fold effect and procedural sound.
5. Integrate the complete input-driven loop, settings, journal, local export/import, shared invite/rejoin.
6. Unit/property diagnostics, real local two-client tests, screenshots/motion/performance, fixes and handoff.

World units: metres, Y up, ground y=0, forward -Z. Courtyard x [-14,14], z [-21,16]; start (0,10), NPC (-3,6), lantern (4,1), teaching encounter (0,-4), spell discovery (-5,-9), guardian (0,-14), observatory (0,-22). Static forgiving collision. One shared zone.

Boundaries: renderer consumes snapshots/events and never applies rules. DOM owns text/input panels. Saves contain serializable state only. No server animation timers or frame simulation. Native concept art is reference only. Runtime evidence comes from browser.

Local first. Cloudflare resources must not be created or modified and deployment must not run. Actual account Free configuration is unverified.
